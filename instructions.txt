================================================================================
DATA AUGMENTATION (CRITICAL FOR SMALL DATASETS)
================================================================================

The enhanced augmentation script creates a new dataset with both original + augmented images.
This is ESSENTIAL for small datasets (< 200 images) to improve accuracy.

# Standard augmentation (10x copies per image, medium severity)
# Input: 50 train images → Output: 550 train images (50 original + 500 augmented)
python src/data_preparation/augment_data.py --input data/yolo --output data/yolo_augmented_enhanced --factor 10 --severity medium

# Heavy augmentation for very small datasets (20x copies, more aggressive transforms)
python src/data_preparation/augment_data.py --input data/yolo --output data/yolo_aug_heavy --factor 20 --severity heavy

# Light augmentation (5x copies, minimal transforms)
python src/data_preparation/augment_data.py --input data/yolo --output data/yolo_aug_light --factor 5 --severity light

# Also augment validation set (useful for very small datasets < 100 total images)
python src/data_preparation/augment_data.py --input data/yolo --output data/yolo_augmented --factor 10 --augment-val --val-factor 3

# After augmentation, train with the new dataset
python src/train/train_yolo.py --mode train --data data/yolo_augmented_enhanced/dataset.yaml --epochs 300 --model-size m --batch 8 --imgsz 1280

# Key benefits:
# - Includes original data + augmented versions
# - Smart augmentation preserves small objects (fibers)
# - Class-aware statistics
# - 10-20x more effective training data
# - Better generalization and accuracy
